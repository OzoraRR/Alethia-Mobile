# Security reporting

Please do not disclose suspected vulnerabilities in a public issue or include passwords, access tokens, server keys, or personal data in a report.

**Monitored security contact: not configured yet.** Before this repository is made public or the service accepts real users, the project owner must enable private vulnerability reporting or add a monitored security email and ensure maintainers can receive reports. Until then, this repository does not provide a verified private disclosure channel.

For maintainers, see [the backend incident-response and backup runbook](backend/docs/BACKUP_AND_INCIDENTS.md).
