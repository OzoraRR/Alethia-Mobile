# Quest artwork

Generated with the built-in imagegen tool, then converted to 256 × 256 lossless WebP with transparent alpha using ImageMagick. Used in the dashboard quest card and quest dialog. Original generated PNGs remain in the Codex generated_images directory.

Shared prompt: Use case: stylized-concept. Asset type: transparent quest icon for Alethia Android pixel cyber-security game UI. A single simple readable pixel-art icon, centered square composition, no text, no letters, no badge frame, no background, true transparent alpha. Consistent limited palette: muted chartreuse #83AE39, pale lime #B2D579, deep teal #1C3733, dark navy #10191F. Hard blocky pixel edges, minimal 32x32 sprite aesthetic enlarged crisply, 2-3 flat shades, no gradients, no bloom, no soft shadows, no tiny clutter. Icon fills about 75 percent of square with generous transparent margin.

Subjects and output files:
- quest_phishing.webp: an email envelope caught on a fishing hook, communicating phishing investigation; one envelope and one hook only.
- quest_fortress.webp: a sturdy cybersecurity shield with a central keyhole and tiny block battlements at its top, communicating a digital fortress.
- quest_impersonation.webp: a simple disguise eye mask partially overlapped by a small magnifying glass, communicating unmasking an impostor.

Assets: app/src/main/res/drawable-nodpi/quest_*.webp.
